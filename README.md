MySQL Data Analysis Project

📌 Project Overview
This project performs exploratory data analysis on an e-commerce sales dataset using MySQL. The goal is to extract key business insights regarding sales performance, product trends, and payment preferences.

🛠️ Key SQL Concepts Used
* Data Retrieval: `SELECT`
* Filtering: `WHERE` clause
* Grouping & Sorting: `GROUP BY`, `ORDER BY`
* Aggregations: `COUNT()`, `SUM()`, `AVG()`, `ROUND()`

📊 Key Queries & Insights
1. High Value Shipped Orders: Filtered completed high-value orders above $1000.
2. Product Sales Summary: Grouped orders by product to analyze overall revenue generation and average order size.
3. Payment Preferences: Aggregated transactions by payment method to evaluate consumer preference.
